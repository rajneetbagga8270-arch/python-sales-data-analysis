# Python Sales Data Analysis

## Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a sales dataset using Python. The analysis cleans raw data, calculates business KPIs, identifies sales trends, and creates visual reports.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- CSV datasets

## Dataset

The project contains **600 sales transactions from 2025**.

The raw dataset includes intentional data-quality issues such as:
- Missing quantities
- Missing discounts
- Extra spaces in text fields
- Inconsistent capitalization

These issues are cleaned using Pandas.

## Project Workflow

1. Loaded raw sales data using Pandas.
2. Inspected the dataset for missing and inconsistent values.
3. Cleaned text and missing values.
4. Created calculated columns for gross sales, discounts, and net sales.
5. Performed exploratory data analysis.
6. Analyzed sales by region, product, category, and month.
7. Created visualizations using Matplotlib.
8. Generated CSV reports from the analysis.

## Key KPIs

- Total Revenue: $531,085.25
- Total Orders: 600
- Unique Customers: 149
- Units Sold: 2,730
- Average Order Value: $885.14

## Key Findings

- Highest revenue region: **North**
- Top product by revenue: **Laptop**
- Highest revenue month: **Jun**
